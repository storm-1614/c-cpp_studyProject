# 组合逻辑电路

## 概述
逻辑电路：组合逻辑电路与时序逻辑电路  
组合逻辑：  
(1) 输出、输入之间没有反馈通路  
(2) 电路中不含具有记忆功能的元件  

给定逻辑电路确定其逻辑功能：逻辑电路的分析。  
根据要求完成的逻辑功能，

组合逻辑电路：电路在某一时刻的输出，仅取决于该时刻的输入，而与之前的输入状态无关。  

$$
Y=F(A,B,C...)
$$

组合逻辑电路没有存储状态的功能。   
## 分析
由逻辑图写表达式。  
化简表达式  

---

根据电路图写出逻辑表达式：  

| 逻辑门      | 表达式             |
|-------------|--------------------|
| 与门 AND    | $Y=AB$             |
| 或门 OR     | $Y=A+B$            |
| 非门 NOT    | $Y=\overline{A}$   |
| 与非门 NAND | $Y=\overlineP{AB}$ |
| 或非门 NOR  | $Y=\overline{A+B}$ |
| 异或门 XOR  | $Y=A\oplus B$      |


多路电路分析：沿信号传播方向，从输入到输出，逐级写出表达式。  

分析多级组合逻辑电路时，可以为每一级的中间信号命名，分别写出表达式，最后代入化简。
