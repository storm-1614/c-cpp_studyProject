## 计算机内部为何要采用层次化存储体系结构？层次化存储体系结构如何构成？
CPU 做运算可能非常快，但是获取数据不一定快。如果 CPU 每次都必须等待较慢的内存提供数据，即使 ALU 运算速度再快，也无法充分发挥性能。  
现实中的存储器面临三个相互制约的指标：  
- 速度: 数据访问需要多少时间
- 容量：可以存储多少数据
- 成本：每一位数据的存储成本有多高  
速度越快的存储器，单位容量成本越高，也难以做得特别大。所以就需要采用层次化存储体系结构。  

所以采用层次化体系结构，分为以下几个层次：  

| 层次 | 存储器 | 主要作用 |
| --- | --- | --- |
| 第 1 层 | CPU 寄存器 | 保存正在参与运算的数据 |
| 第 2 层 | Cache | 缓存 CPU 近期可能使用的数据 |
| 第 3 层 | 主存 | 存放正在运行的程序及其数据 |
| 第 4 层 | 辅助存储器 | 长期保存程序和文件 |


存储器按照速度由快到慢、容量由小到大，通常划分为寄存器、Cache、主存和辅助存储器等层次。各层次通过数据交换和程序访问的局部性原理相互配合使整个存储系统在较低成本下获得接近高速存储器的访问性能和接近低速大容量存储器的容量。  
## SRAM 芯片和 DRAM 芯片各有哪些特点？各自用在哪些场合？
SRAM 和 DRAM 都属于 RAM 也就是随机存取存储器，也就是易失性存储器，断电后数据都无法保存。  
SRAM 是静态随机存取存储器。典型存储单元由 6 个晶体管组成，其中两个交叉耦合的反相器构成双稳态电路。其的电路能稳定保持两种状态：  
- 状态一：保存二进制 0
- 状态二：保存二进制 1  

只要正常供电、没有执行新的写入操作，电路就可以持续保持原来的状态所以被称为静态存储器。  
SRAM 的特点：  
- 不需要周期性刷新
- 访问速度快
- 存储单元电路较复杂，集成密度相对低
- 通常用于 CPU 的 Cache

DRAM 是动态随机存取存储器。典型的 DRAM 存储单元采用：  
- 1 个晶体管
- 1 个电容

所以也叫 1T1C 结构，它通过电容是否存有足够的电荷来区分二进制 0 和 1 。但是电容存在漏电现象。即使不存取数据，随着时间推移，电容保存到电荷也可能减少到无法可靠区分数据的程度。所以 DRAM 必须进行周期性刷新，也就是在数据丢失之前，重新恢复存储单元中的电荷状态。  

DRAM 的特点：  
- 需要周期性刷新
- 访问速度通常比 SRAm 慢
- 存储单元结构简单，集成密度高
- 单元容量成本较低
- 主要用于计算机的主存

而且 DRAM 的读出具有破坏性，需要通过感应放大器恢复被读取单元的数据。  
## CPU 和主存之间有哪两种通信定时方式？SDRAM 芯片采用什么方式和 CPU 交换信息？
通信定时方式：  
- 同步通信
- 异步通信  

同步通信的基本思想是：CPU 侧的存储控制器和存储器遵循约定的时钟时序，在指定的时钟边沿发送命令、传输或采样数据。其主要特点：  
- 使用共同约定的时钟时序
- 操作按时钟周期协调
- 便于组织流水线和连续数据传输
- 需要满足约定的建立时间、保持时间和访问延迟等时序要求

然后就是异步通信，异步通信不依赖统一的时钟边沿来确定整个传输完成时刻。其一种典型实现方式是：请求-应答握手。其的特点：  
- 不要求双方按同一个时钟边沿完成传输
- 能够适应不同响应速度的设备
- 握手式通信需要额外的控制型号和协调过程  

不过异步接口不一定都采用握手协议。例如传统异步 DRAM 也可以使用 RAS、CAS 等控制信号及规定的时间间隔完成访问。  

对于 SDRAM，先拆开来看 SDRAM 的完整名称是： Synchronous Dynamic Radom Access Memory，中文译名是同步动态随机存取存储器。   
所以 SDRAM 本质上是 DRAM 同样利用电容存储数据，也需要刷新。但 SDRAM 的命令和数据传输采用同步时序，通常由内存控制器提供时钟。也就是说：**SDRAM 采用的是同步通信方式**。    


## 为什么在 CPU 和主存之间引入 cache 能提高 CPU 访存效率？
首先需要知道 Cache 的访问速度比主存快。且程序访问具有局部性，使得 CPU 请求的数据经常已经在 Cache 中。  
对于程序访问的局部性分为时间局部性和空间局部性。  
- 时间局部性：某个数据刚被访问过，近期可能再次被访问
- 空间局部性：访问某个存储单元后，近期可能访问附近的存储单元  

这里的 Cache 通常不是每次只装入一个变量，而是以 Cache 块为单位在 Cache 和主存之间传输数据。

所以根据程序访问的时间局部性和空间局部性，将近期访问或可能访问的指令与数据块存放在 Cache 中，使 CPU 的大部分访存请求能够直接命中 Cache，从而减少对较慢主存的访问，缩短平均访存时间，提高访存效率。  
## 为什么说 cache 对程序员来说是透明的？
首先，计算机体系中的透明指的是某个机制的内部实现细节，对某一层的使用者来说通常不需要显式感知或管理。  

Cache 的访问、数据调入、替换等操作通常由硬件自动完成，不需要程序员显式管理。程序员按照正常方式访问内存即可，无须关心所访问的数据在 Cache 中存放位置。因此，Cache 对程序员是透明的。但 Cache 的命中情况会影响程序的运行性能。  

## 什么是 cache 映射的关联度？关联度与命中率、命中时间的关系各是什么？
Cache 映射就是规定主存中的某个块，可以放到 Cache 的哪些位置。主要有三种映射方式：  
1. 直接映射
2. 全相联映射
3. 组相联映射

直接映射到规则就是：  $Cache 行号 = 主存块号 \mod Cache 总行数$  
全相联映射可以放到任意一行，组相联映射：直接映射和全相联的折中。  

Cache 的关联度就是一个主存映射到指定 Cache 组后，在该组内可以选择的 Cache 行数，也称为路数。  

关联度与命中率关系：在 Cache 总容量与块大小相同的条件下，提高关联度，通常可以减少冲突不命中。一般有趋势：关联度提高使得命中率提高。  

关联度与命中时间的关系：关联度增加后，同一组需要检查的候选位置更多。比如：  
- 直接映射：只需要检查一个候选行
- 4 路组相联：需要检查最多 4 个候选行的标记
- 全相联：需要检查整个 Cache 的候选行


因此通常需要更多的比较电路以及选择逻辑，可能导致命中时间增加。也就是说关联度提高，会使得命中时间可能的增加。  

所以说：Cache 的关联度需要在命中率、命中时间和硬件成本之间进行权衡。  
## 为什么直接映射方式不需要考虑替换策略？
直接映射中，每个主存块只能放到 Cache 中唯一指定的一行。当新块映射到这一行时，如果该行已有其他块，旧块就会被新块覆盖，不存在多个候选行可供选择。因此，直接映射不需要选择“替换哪一行”的策略；映射规则本身已经确定了被替换的位置。
## 为什么要考虑 cache 的一致性问题？读操作时是否要考虑 cache 的一致性问题？为什么？
当多个处理器核心或设备各自缓存了同一内存位置的数据时，其中一处写入后，其他缓存中的副本可能仍是旧值。Cache 一致性机制用于协调这些副本，使后续访问能够得到符合一致性规则的数据。

读操作也要考虑一致性。读本身通常不会修改数据，但可能读到其他核心写入之前留下的旧副本；一致性协议会在读取时检查或协调缓存状态，必要时使副本失效、更新副本或从较新数据所在处取数。因此，读操作是否命中 Cache，不能绕过一致性要求。
## 什么是物理地址？什么是逻辑地址？地址转换由硬件还是软件实现？为什么？
逻辑地址（在虚拟内存语境下通常称虚拟地址）是程序执行时使用的地址；物理地址是主存硬件实际使用的地址。通常由 CPU 中的内存管理单元（MMU）在访存时完成地址转换，页表提供逻辑页到物理页框的映射，快表（TLB）缓存近期使用的映射以加快转换。操作系统负责建立和维护页表、设置访问权限等，硬件负责每次访存时快速查表和检查权限。这样既能让程序使用相互独立的地址空间，也便于内存保护和主存分配。
## 什么是页表？什么是快表？什么是慢表？
页表是操作系统为进程维护的数据结构，记录虚拟页到物理页框的映射及相关状态、权限信息。快表通常指 TLB（页表项缓存），由硬件快速查询，用来保存近期使用的地址映射。慢表通常指存放在主存中的页表；TLB 未命中时，处理器需要访问主存中的页表（多级页表还可能需要多次访问）来查找映射，因此较慢。
## 在存储器层次结构中，“cache‑主存”“主存‑磁盘” 这两个层次有哪些不同？
Cache—主存层次主要弥补处理器与主存之间的速度差距，利用程序访问的局部性，以 Cache 块为单位调入和替换数据，通常由硬件自动管理；主存—磁盘层次主要弥补主存容量有限的问题，以页或文件块等为单位在主存与外存之间调入数据，通常由操作系统和文件系统管理，缺页等情况需要软件处理。两层的速度、容量和单位容量成本也不同：Cache 更快、容量更小、单位容量成本更高；磁盘速度较慢、容量较大、单位容量成本较低。此外，主存通常是易失性存储器，磁盘用于持久保存数据。
