# 1-单片机概述

ALU(Arithmetic Logic Unit)：算术逻辑单元
CU(Controll Unit)：控制单元  

单片机是可编程的集成电路芯片。  
单片机是在一块芯片上集成了 CPU、存储器、输入/输出接口、定时器/计数器和中断系统等部件的微型计算机。  

Intel 8051 单片机。  

在应用上的定义：嵌入式系统实施用于控制、监视或者辅助操作机器和设备的装置。  

核心特点：  
- 专用性  
- 实时性  
- 资源受限  

## 嵌入式系统架构
- 软件  
- 硬件  
    * I/O

实时多任务，具有存储区保护功能，功耗很低。  

嵌入式处理器分类：  
### 嵌入式微控制器(MCU)
内部集成非常多的单元和外设。  
最大特点是单片化。适合用于控制。  
### DSP
专门用于信号处理方面的处理器：w。  
拥有极高乘加运算(MAC)速度和强大的实时数据处理能力。  

数字信号。  

### 嵌入式微处理器 MPU
相对 MCU 系统可靠性降低。  
相对商用 CPU 体积小、重量轻、成本低、可靠性高。。 

### 嵌入式片上系统 (System On Chip)
SoC，结合多个区块。
