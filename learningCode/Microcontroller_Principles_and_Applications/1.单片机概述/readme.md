# 1-单片机概述

ALU（Arithmetic Logic Unit）：算术逻辑单元
CU（Control Unit）：控制单元

单片机是可编程的集成电路芯片。
单片机是在一块芯片上集成了 CPU、存储器、输入/输出接口、定时器/计数器和中断系统等部件的微型计算机。

8051 系列单片机（最初由 Intel 推出）。

嵌入式系统是嵌入设备内部，用于控制、监视或者辅助操作机器和设备的专用计算机系统。

核心特点：  
- 专用性  
- 实时性  
- 资源受限  

## 嵌入式系统架构
- 应用程序
- 软件平台
  - 操作系统或实时操作系统（可选）
  - 驱动程序
- 硬件平台
  - 处理器（MCU、MPU 或 SoC）
  - 存储器
  - I/O 接口
  - 定时器、通信接口等外设

嵌入式系统通常具有专用性、实时性、资源受限、可靠性和低功耗等特点；是否支持多任务和存储区保护，取决于具体的处理器及软件平台。

嵌入式处理器分类：  
### 嵌入式微控制器(MCU)
MCU（Microcontroller Unit）将 CPU、存储器、I/O 端口、定时器、通信接口等多种功能集成在一块芯片中。
最大特点是高度集成，适合用于实时控制。
### DSP
DSP（Digital Signal Processor，数字信号处理器）是专门用于数字信号处理的处理器。
DSP 通常针对乘累加运算（MAC，Multiply-Accumulate）和流式数据处理进行了优化，具有较强的实时数据处理能力。

### 嵌入式微处理器 MPU
MPU（Microprocessor Unit，嵌入式微处理器）通常具有更强的处理能力，但需要外接存储器和其他外设，系统设计复杂度通常高于 MCU。
与通用商用 CPU 相比，嵌入式 MPU 通常更注重体积、功耗、成本和应用适配性；其可靠性取决于具体的系统设计。

### 嵌入式片上系统 (System On Chip)
SoC（System-on-Chip，片上系统）是将处理器核心、存储器控制器、通信接口、图形处理单元或其他专用加速单元等集成在一块芯片上的系统。

### AI 芯片
面向人工智能和机器学习任务设计的专用处理器，通常针对神经网络中的矩阵运算、向量运算和并行计算进行优化。

### 嵌入式的应用
常见于智能仪器、工业控制、家用电器、计算机网络与通信设备、医疗设备、汽车电子、航空航天等领域。

### 嵌入式系统技术发展趋势
常见趋势包括低功耗、高性能、网络化、智能化、集成化和实时性增强。
