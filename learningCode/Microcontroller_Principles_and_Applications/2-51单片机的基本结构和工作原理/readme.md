# 51单片机的基本结构和工作原理

## 单片机的最小系统
最小系统：通过对单片机引脚的简单连接，使单片机开始独立工作。  
主控芯片+电源+时钟电路+复位电路。  

时钟：晶振。给出方波的阶梯状电路。  

## 引脚
MCS-51 单片机的引脚：50 只引脚双列直插封装(DIP)  

大致分三类：  
- 电源以及时钟(Vcc, Vss, XTAL1, XTAL2)  
- 控制(PSEN*, EA*, ALE, RESET)  
- I/O(PO, P1, P2, P3,为 4 个八位, I/O 的外部引脚)  

### 电源引脚
Vcc (40 脚)接 +5V 电源  
Vss (20 脚)接地  
提供稳定电源。  

### 时钟引脚
XTAL1, XTAL2(18, 19 脚)  产生时钟信号（上升沿信号）以驱动单片机工作。  
通常外接一个晶振两个电容，也可以由 XTAL 1 端接入外部时钟，此时 XTAL 2 接地。  


### 控制引脚
提供控制号，有的引脚还具有复用功能。  
RST：产生复位信号（高电平），使单片机从初始状态（ROM 首地址放的第一条语句）开始执行，包括手动按键复位，上电复位。  
控制引脚：PSEN*, EA*< ALE, RESET。  


### I/O 引脚
MCS-51 有 4 个 8 位的并行 I/O 端口，P0, P1, P2,P3 口，共 32 个引脚。  

P3 口有第二功能，用于特殊信号输出输入和控制信号，归属控制总线部分。  

|P3口引脚|第二功能|
|--|--|
|P3.0|RXD：串行口数据接收|
|P3.1|TXD：串行口数据发送|
|P3.2|INT0：外部中断0输入|
|P3.3|INT1：外部中断1输入|
|P3.4|T0：定时器/计数器0外部输入|
|P3.5|T1：定时器/计数器1外部输入|
|P3.6|WR：外部数据存储器写选通|
|P3.7|RD：外部数据存储器读选通|

## 内部结构
以存储器为中心的计算机硬件体系：冯诺依曼结构。  
简单、便宜、灵活、并行性差。  

**哈佛结构**：指令和数据分开独立存储，独立编址，独立访问。  
并行性高，速度快，复杂，灵活度（数据、地址页的灵活调整）低。  


改进型哈佛结构：保留两个存储器，合并总线，分时公用。

## 单片机结构组成
1. CPU
2. 程序存储器(ROM/EPROM)   
    * 8031 无此部件
    * 8051 4K 字节 ROM
    * 8751 4k字节 EPROM
    * 89C51 89C52 89C55: 4k/8k/20k 字节闪存  
3. 数据存储器(RAM)
4. 中断系统
5. 定时器/计数器
6. 串行口
    1 个全双工的异步串行口。  
7. 4 个并行可编程的 8 位 I/O 口
8. 特殊功能寄存器(SFR)
9. 时钟电路

CPU:  
1. 运算器：算术逻辑运算和微操作：ALU, 累加器、寄存器、位处理器、程序状态字寄存器、BCD码修正电路    
    * ALU 对八位变量进行算术运算还有与或非等逻辑运算，还有位处理  
    * 累加器A：使用最频繁的寄存器：ACC  
        是ALU的输入之一，又是运算结果的存放单元

```asm
add a,#34H
mov a,r0
```
* 寄存器B：存放结果的另一个单元，进行乘法8*8把高 8 位放到寄存器 B 里，低 8 位放到累加器 A 中。  
* 程序状态字寄存器 PSU：标志寄存器：有 8 位，用于存放各有关标志：  

``` python
Cy # 进位标志器
Ac # 辅助进位标志
F0 # 用户使用的状态标志位
RS1 # 在 4 组工作寄存器中选择 1 组
RS0
OV # 溢出标志位
- # 保留位
P # 奇偶标志位 1 奇0偶
```

```
7fh + 01h  
```

CY = 0, AC=1, P=1,OV=1  
CY, AC,OV 由运算更新，P 随累加器 A 的内容自动更新
